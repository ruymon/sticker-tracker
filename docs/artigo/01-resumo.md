# Resumo

O Cola Aí é um aplicativo desktop para acompanhamento de álbuns de figurinhas da Copa do Mundo FIFA 2026. O sistema resolve um problema comum entre colecionadores: saber quais figurinhas já foram obtidas, quais ainda faltam e quais estão repetidas para troca. A aplicação foi desenvolvida exclusivamente em Java, com interface gráfica construída manualmente em Swing, sem uso de geradores visuais. Para armazenamento persistente dos dados foi utilizado MySQL, acessado por JDBC através do driver oficial Connector/J. O ambiente de banco foi isolado com Docker, facilitando a reprodução do projeto em diferentes computadores. A arquitetura adotada separa domínio, repositórios, infraestrutura e interface, mantendo as responsabilidades claras e reduzindo dependências desnecessárias entre partes do sistema. O projeto também utiliza componentes gráficos reutilizáveis, um sistema de tema centralizado e carregamento assíncrono com SwingWorker para evitar travamentos na interface. Como resultado, foi entregue um aplicativo funcional com tela inicial de progresso, álbum completo, filtros, busca, controle de quantidade e lista de figurinhas repetidas para troca.
