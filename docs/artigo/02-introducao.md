# Introdução

A Copa do Mundo FIFA 2026 mantém viva uma tradição muito forte no Brasil: colecionar figurinhas, completar páginas por seleção e trocar repetidas com amigos. Apesar de simples, esse hábito rapidamente se torna difícil de controlar quando o álbum possui centenas de itens. Sem uma ferramenta de apoio, o colecionador precisa consultar páginas manualmente, anotar repetidas em papel ou depender de mensagens soltas para organizar trocas.

O problema central do projeto é oferecer uma forma simples de responder três perguntas: quais figurinhas eu tenho, quais ainda faltam e quais posso trocar. Para isso, o Cola Aí foi desenvolvido como um aplicativo desktop executado em computadores pessoais, com interface gráfica própria e persistência em banco de dados MySQL.

A solução proposta inclui uma tela inicial com resumo do progresso da coleção, uma tela de álbum com todas as seções e figurinhas, filtros por situação, busca por código ou nome e controle de quantidade por figurinha. O sistema também permite visualizar repetidas e copiar uma mensagem formatada para facilitar trocas.

O escopo foi mantido simples de forma intencional. A versão atual não inclui login, sincronização online, múltiplos usuários ou negociação automática de trocas. Essas funcionalidades seriam evoluções naturais, mas não são necessárias para demonstrar os conceitos de Java, Swing, JDBC, MySQL e organização de código exigidos pela disciplina.
